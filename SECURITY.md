# Security policy

Do not commit passwords, cookies, browser profiles, player or staff data,
birth dates, screenshots containing personal data, or production request
captures.

The application is deliberately limited to authorised, user-reviewed concept
actions. It has no programmatic e-Kickoff save or official submission action.
If you find a way to bypass those protections or expose sensitive data, report
it privately to the repository owner rather than opening a public issue.

## Optional support form

The Dry-run Wizard's optional support checkbox is off by default. It has no
GitHub token, API client, telemetry endpoint, or persistent error log. After a
failure it can only open a prefilled public GitHub issue form for the user to
review and submit manually. That form is restricted to a fixed workflow stage,
fixed error category and fixed exception family. It never contains an exception
message, match sheet ID, person, staff member, date of birth, URL, cookie,
browser profile or request data.

Do not use this form for a suspected security or privacy defect. Report that
privately to the repository owner as stated above.
