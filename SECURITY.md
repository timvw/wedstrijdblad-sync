# Security policy

Do not commit passwords, cookies, browser profiles, player or staff data,
birth dates, screenshots containing personal data, or production request
captures.

The application is deliberately limited to authorised, user-reviewed concept
actions. It has no programmatic e-Kickoff save or official submission action.
If you find a way to bypass those protections or expose sensitive data, report
it privately to the repository owner rather than opening a public issue.
